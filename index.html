Employee Directory

10,000행 실데이터 템플릿 — 가상 스크롤, 정렬(Shift 멀티), 컬럼 필터 메뉴, 헤더 필터 행, 퀵 필터, 행 그룹핑·집계, 체크박스 선택, 페이지네이션, 클립보드 복사/붙여넣기(Ctrl+C/Ctrl+V), CSV 내보내기를 한 화면에서 사용합니다. 인라인 편집은 모든 에디터 종류를 한 번에 보여줍니다 — text · number · select · searchselect(검색형) · radio · multiselect · 검색형 multiselect(Certifications — 검색 + 칩) · checkbox · date · datetime · 커스텀(range 슬라이더). 헤더에 연필 아이콘이 있는 컬럼이 편집 가능한 컬럼입니다(editableIndicator). 툴바의 Edit in form은 같은 컬럼 정의를 그대로 재사용하는 행 단위 폼 편집(popupEditor)을 엽니다 — 더블클릭은 인라인 편집 그대로라 두 방식을 나란히 비교할 수 있습니다. Lock selected는 setRowEnabled로 선택한 행을 잠가 편집과 선택을 함께 막습니다 — 권한이나 결재 상태로 일부 행만 읽기 전용으로 두는 경우입니다. View Source 탭에서 전체 코드를 확인하세요.
