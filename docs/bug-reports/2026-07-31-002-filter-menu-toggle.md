# BUG-002: 필터 메뉴 버튼 재클릭으로 닫히지 않음 (토글 불가)

| 항목 | 내용 |
|---|---|
| ID | BUG-002 |
| 보고일 | 2026-07-31 (사용자 제보) |
| 수정일 | 2026-07-31 |
| 심각도 | Medium — 기능 손실은 없으나(바깥 클릭으로는 닫힘) 보편적인 토글 기대와 어긋남 |
| 영향 버전 | v1.0.0 ~ |
| 영향 범위 | 모든 컬럼 필터 메뉴(text/number/set), 모든 페이지 |

## 증상

헤더의 필터 메뉴 버튼을 클릭하면 팝업이 정상적으로 열리지만, **같은 버튼을 한 번 더
클릭해도 팝업이 닫히지 않고 계속 열려 있다.** 바깥 영역 클릭으로는 정상적으로 닫힌다.

## 재현 절차

1. `examples/features.html`의 Column Filters 예제(아무 페이지나 동일)
2. 아무 컬럼의 헤더 메뉴 버튼 클릭 → 팝업 열림
3. 같은 버튼을 다시 클릭 → 팝업이 닫히지 않음 (재현율 100%)

## 원인 분석

두 이벤트 핸들러의 상호작용으로, 두 번째 클릭에서 메뉴가 **"닫힌 뒤 즉시 다시 열리는"**
시퀀스가 됨. 브라우저 계측으로 확정:

| 두 번째 클릭의 단계 | 동작 | 계측 결과 |
|---|---|---|
| ① `mousedown` (버튼 위) | document의 바깥클릭 핸들러 `closeMenus`가 실행 — 버튼은 `.dg-menu` 바깥이므로 메뉴를 닫음 | `menuOpen: false` |
| ② `click` (버튼) | 버튼의 click 핸들러가 `_openFilterMenu()` 호출 — 새 메뉴 element를 다시 엶 | `menuOpen: true`, `isNewElement: true` |

또한 버튼 click 핸들러에 "이미 열려 있으면 닫기" 토글 분기 자체가 없었다
(`_openFilterMenu`는 항상 `_closeMenu()` 후 재오픈).

## 수정 내용

`dist/datagrid.js` 두 곳:

1. **`closeMenus`(document mousedown)**: mousedown 대상이 *현재 메뉴를 연 컬럼의
   메뉴 버튼*이면 닫지 않고 그대로 둔다 — 닫아버리면 이어지는 click에서 재오픈되어
   토글이 불가능해지기 때문. 다른 컬럼의 메뉴 버튼이나 바깥 영역은 기존대로 닫는다.
2. **메뉴 버튼 click 핸들러**: `self._menuHeaderCell === cell`(같은 컬럼 메뉴가 열려
   있음)이면 `_closeMenu()`로 닫고 반환 — 토글 분기 추가.

## 검증 (수정 후, 실제 mousedown→mouseup→click 시퀀스로 재연)

- 같은 버튼 재클릭 → 닫힘 (토글) ✓
- 메뉴 열린 상태에서 **다른 컬럼** 버튼 클릭 → 기존 메뉴가 닫히고 해당 컬럼 메뉴로 전환(동시 1개, 하이라이트 이동) ✓
- 바깥 클릭으로 닫힘 (회귀 없음) ✓
- 메뉴 내부 클릭은 유지, Apply/Clear 정상 동작 + 필터 활성 아이콘 표시 ✓
- 콘솔 에러 0, 단위 테스트 93개 통과 (데이터 로직 무변경) ✓

## 재발 방지

1. **규칙**: "버튼으로 여는 팝업"은 반드시 (a) 같은 버튼 재클릭 = 토글 닫기,
   (b) 바깥클릭 핸들러에서 그 버튼의 mousedown 제외 — 두 가지를 세트로 구현한다.
   바깥클릭 닫기(mousedown)와 버튼 열기(click)는 **다른 이벤트 단계**라서,
   제외 처리가 없으면 "닫힘→재오픈"으로 토글이 침묵 실패한다.
2. **검증 절차 보강**: 팝업류 UI는 열기뿐 아니라 *같은 트리거 재클릭(토글)*,
   *다른 트리거로 전환*, *바깥 클릭* 세 시나리오를 실제 이벤트 시퀀스
   (mousedown→mouseup→click)로 검증한다. `element.click()`만으로는 mousedown
   단계의 상호작용이 재현되지 않는다.
3. 향후 컨텍스트 메뉴(로드맵 §2.5) 등 팝업 계열 구현 시 BUG-001과 함께 선행 참조.
