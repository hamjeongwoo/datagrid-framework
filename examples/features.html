Template Features Components API Docs

Features

기능별 데모 — 각 예제의 View Source 탭에 표시되는 코드가 그대로 실행됩니다. 복사해서 바로 사용할 수 있는 완결된 예제입니다.

Sorting

헤더 클릭으로 오름차순 → 내림차순 → 해제 순환. Shift+클릭으로 다중 정렬(정렬 순서 배지 표시). sortModel로 초기 정렬을 지정할 수 있습니다.

Column Filters

헤더에 마우스를 올리면 나타나는 메뉴 버튼으로 컬럼별 필터를 엽니다. filter: 'text' · 'number' · 'set'. 여러 컬럼 필터는 AND로 결합됩니다.

Quick Filter

모든 컬럼을 대상으로 한 전역 검색 — 공백으로 구분된 모든 단어가 일치해야 합니다.

Row Selection

rowSelection: 'multiple' — 체크박스, 헤더 전체 선택(부분 선택 시 indeterminate), Ctrl/⌘+클릭 토글, Shift+클릭 범위 선택.

선택된 행 없음

Cell Editing

editable: true 셀을 더블클릭(또는 Enter)하면 편집 시작 — text / number / select 에디터, Enter 커밋, Esc 취소, cellValueChanged 이벤트 발행.

셀을 더블클릭해 편집해 보세요.

Pagination

페이지 크기 선택, 처음/이전/번호/다음/마지막 버튼, "X to Y of Z" 요약. 페이지네이션을 끄면 전체 가상 스크롤로 동작합니다.

Column Pinning · Resize · Reorder

pinned: 'left' | 'right' 고정 컬럼(스크롤 시 그림자), 헤더 경계 드래그로 크기 조절, 경계 더블클릭으로 자동 맞춤, 헤더 드래그로 순서 변경.

Row Virtualization — 100,000 rows

보이는 범위(±6행 버퍼)만 DOM으로 렌더링해 10만 행도 지연 없이 스크롤합니다.

현재 DOM row 수: –

CSV Export

필터·정렬이 적용된 현재 뷰 데이터를 그대로 내보냅니다(포매터 적용, RFC 4180 이스케이프).

Overlays

로딩 스피너 오버레이와 "No rows to show" 빈 상태.

Row Grouping & Aggregation

groupBy: ['department']로 행을 그룹핑하고, 그룹 헤더 행을 클릭(또는 Enter)해 접고 펼칩니다. aggFunc: 'sum' | 'avg' | 'min' | 'max' | 'count'를 컬럼에 지정하면 그룹 헤더와 grandTotal 요약 행에 집계값이 표시됩니다. 다단계 그룹핑(['department', 'city'])도 지원합니다.

그룹 헤더 행을 클릭해 접고 펼쳐 보세요.

Floating Filter (헤더 필터 행)

floatingFilter: true — 헤더 바로 아래에 컬럼별 인라인 필터 입력을 표시합니다. text/number는 입력하는 대로(250ms 디바운스) 필터링되고, set은 드롭다운으로 단일 값을 고릅니다. 필터 메뉴와 같은 필터 모델을 공유하므로 Esc로 지우거나 메뉴에서 바꾼 내용이 서로 반영됩니다.

헤더 아래 입력란에 바로 입력해 보세요.

Edit Validation & Programmatic Control

column.validator(value, row)가 true가 아닌 값(오류 메시지 문자열)을 반환하면 커밋이 거부되고 편집기가 빨간 테두리로 유지됩니다(Esc로 취소). beforeCellSave 이벤트에서 e.cancel = true로 저장을 막을 수 있고, startEdit(row, field) / stopEdit(commit) / isEditing()으로 편집을 코드로 제어합니다. 편집 수명주기는 editingStarted / editingStopped로 관찰합니다.

Name은 2자 이상, Salary는 0 ~ 1,000,000만 저장됩니다. 셀을 더블클릭해 잘못된 값을 넣어 보세요.

Clipboard Copy & Paste (TSV)

선택한 행을 Ctrl+C로 엑셀 호환 TSV로 복사하고(선택이 없으면 포커스 셀), 포커스 셀을 시작점으로 Ctrl+V로 붙여넣습니다 — 편집 가능한 셀에만 쓰이고 validator·beforeCellSave를 통과한 값만 반영됩니다. column.suppressCopy로 복사에서 제외할 컬럼을 지정하고, copy() / pasteTsv(text)로 코드에서도 제어합니다.

행을 선택해 Ctrl+C, 셀을 클릭해 포커스한 뒤 Ctrl+V — Email은 suppressCopy라 복사에서 빠집니다.

Grid State Save & Restore

getState()는 컬럼 순서·숨김·폭, 정렬, 필터, 퀵 필터, 그룹핑, 페이지 상태를 JSON 직렬화 가능한 객체로 반환합니다. localStorage 등에 저장했다가 setState(state)로 복원하고, resetState()로 생성 시점 옵션 기준으로 되돌립니다 (resetState({ sort: true })처럼 부분 리셋도 가능).

정렬·필터·컬럼 폭·순서를 바꾼 뒤 저장 → 다시 흐트러뜨리고 복원해 보세요.

Column Data Type & Declarative Format

dataType: 'number' | 'date' | 'bool'은 정렬 비교· filter: true의 필터 종류·기본 정렬 방향(숫자는 오른쪽)을 자동 결정합니다. format: '$#,##0.00' / 'yyyy-MM-dd' 선언적 포맷은 valueFormatter를 대신하며, 같은 패턴을 DataGrid.format(value, pattern) 유틸로도 쓸 수 있습니다.

Salary/Rating은 dataType: 'number' — 헤더 클릭 정렬이 숫자 기준이고 자동 우측 정렬됩니다.

Row Numbers · Max Width · Grid-level Editable

rowNumbers: true는 왼쪽에 고정된 행 번호 컬럼을 추가합니다(정렬·필터·복사 제외). column.maxWidth는 드래그 리사이즈·flex·자동 맞춤의 상한이 됩니다. 그리드 레벨 editable: false / setEditable(bool)은 컬럼 설정을 무시하고 편집 전체를 잠급니다.

지금은 편집 잠김(editable: false) — Name을 더블클릭해도 편집기가 열리지 않습니다. City는 maxWidth: 160이라 그 이상 넓힐 수 없습니다.

Programmatic Navigation & JSON Export

focusCell(rowIndex, field)는 페이지 이동·스크롤을 포함해 셀에 포커스를 주고, ensureRowVisible(row) / ensureColumnVisible(colId)는 행·컬럼이 보이도록 스크롤합니다. getJson()은 필터·정렬이 적용된 현재 뷰를 JSON 문자열로 반환하고, 셀 더블클릭은 cellDoubleClicked 이벤트를 발생시킵니다.

행 번호를 입력하고 focusCell을 눌러 보세요 — 페이지를 넘어가며 해당 셀이 포커스됩니다. 셀을 더블클릭하면 cellDoubleClicked 페이로드가 표시됩니다.

Lifecycle & Cancelable Events

gridReady(초기 렌더 후 1회) · dataChanged(행 추가/삭제/교체) · viewRendered(모든 refresh 후) 라이프사이클 이벤트와, e.cancel = true로 동작을 거부하는 beforeSort / beforeSelectionChange / beforeCellSave 취소 가능 이벤트 규약입니다.

이벤트 로그가 여기 표시됩니다.

Computed Columns & Row Styling

column.valueGetter(row)는 파생 값을 계산해 행에 기록합니다 — 정렬·필터·CSV/JSON 내보내기 모두 같은 값을 봅니다. getRowClass(row, index)는 행별 CSS 클래스를, column.suppressMove는 특정 컬럼의 드래그 이동을 막습니다.

Total은 Qty × Unit Price로 계산된 컬럼입니다 — Qty를 더블클릭해 수정하면 Total·정렬이 함께 갱신됩니다. 합계 $2,000 이상 행은 강조 표시됩니다. Order ID는 suppressMove라 드래그로 옮길 수 없습니다.

Continuous Editing & Custom Editor

editOnSingleClick(클릭 한 번 편집) · enterMovesDown(Enter로 아래 셀 연속 편집) · tabMovesRight(Tab/Shift+Tab으로 좌우 이동, 행 끝에서 줄바꿈) 옵션과, editor: { init(cell, value, row, col), getValue(), destroy() } 커스텀 에디터 객체입니다. Rating 컬럼은 슬라이더 에디터를 씁니다.

아무 셀이나 클릭하면 즉시 편집 — Enter는 아래로, Tab은 오른쪽으로 이어집니다.

Change Tracking & Undo / Redo

trackChanges: true는 마지막 기준선 이후의 변경을 추적합니다 — 수정 셀은 모서리 마커(dirty), 추가 행은 배경으로 표시되고 getChanges() / commitChanges() / rollbackChanges()로 제어합니다. undoRedo: true는 Ctrl+Z / Ctrl+Y와 undo() / redo()를 활성화합니다.

셀을 더블클릭해 수정해 보세요 — 수정된 셀에 주황 마커가 생기고 undo로 되돌릴 수 있습니다.

Cell / Block Selection & Find

cellSelection: true는 셀 클릭·드래그·Shift+클릭/화살표로 블록 범위를 선택합니다 — Ctrl+C는 범위를 그대로 TSV로 복사하고 getCellRange()로 범위를 읽습니다. findNext(text)는 뷰에서 다음 매치를 찾아 포커스하고(끝에서 처음으로 순환), cellContextMenu / headerClicked / cellKeyDown 이벤트로 상호작용을 확장합니다.

셀을 드래그해 블록을 선택하고 Ctrl+C로 복사해 보세요. 우클릭은 cellContextMenu 이벤트를 발생시킵니다.

Column Group Headers

columnGroups: [{ headerName, children: ['field'...] }]는 헤더 위에 그룹 스팬 행을 추가합니다. 같은 그룹의 연속된 컬럼이 하나의 스팬으로 묶이고, 컬럼을 드래그해 그룹 밖으로 옮기면 스팬이 자동으로 갈라집니다. 고정(pinned) 컬럼 경계에서는 스팬이 끊겨 스크롤과 어긋나지 않습니다.

컬럼 헤더를 드래그해 순서를 바꿔 보세요 — 그룹 스팬이 실시간으로 재계산됩니다.

Remote Data Source (Server-side Sort / Filter / Paging)

dataSource: { url, method, params, parse }는 fetch로 데이터를 불러옵니다. sortMode / filterMode / pageMode: 'server'인 축은 클라이언트 처리를 건너뛰고 현재 상태를 요청 파라미터(page·pageSize·sort·filter·quickFilter)로 보냅니다. reloadData()로 다시 불러옵니다. 이 데모는 데모 서버의 /api/employees(500행)를 사용합니다.

헤더를 클릭하면 정렬을 서버가 수행하고, 페이지를 넘기면 해당 페이지만 받아옵니다.

Master-Detail Rows

rowDetail: { renderer(row), height }는 행 아래에 커스텀 디테일 패널을 펼칩니다. 첫 컬럼의 셰브론(자동 추가)이나 expandRow(row) / collapseRow(row) / toggleRowDetail(row)로 제어하고 rowExpanded / rowCollapsed 이벤트가 발생합니다. 디테일 높이는 가상 스크롤 레이아웃에 정확히 반영됩니다. (renderer 반환 HTML은 이스케이프되지 않으므로 신뢰할 수 있는 마크업만 사용하세요.)

행 앞의 ▸ 를 클릭해 디테일 패널을 펼쳐 보세요.

Partial Refresh · Runtime Options · Title / Toolbar

refreshCell(row, field) / refreshRow(row) / refreshColumn(colId)은 전체 재계산 없이 렌더된 DOM만 다시 그립니다 (대량 데이터에서 실시간 값 갱신용). setOptions({...})는 재생성 없이 옵션을 바꾸며, title 옵션과 toolbar 슬롯 (소비자 DOM 주입)으로 그리드에 상단 UI를 붙입니다.

타이틀 바와 툴바 슬롯은 그리드 안에 렌더링된 것입니다 (title / toolbar 옵션).

Excel Export & beforeExport

exportExcel(filename, sheetName)은 의존성 없이 진짜 .xlsx 파일을 만듭니다 (무압축 ZIP + SpreadsheetML — 포매터 없는 숫자는 숫자 셀로 나가 엑셀에서 바로 계산 가능). beforeExport 이벤트로 내보내기를 취소하거나 rows/columns/filename을 가공하고, column.exportFormatter는 화면 표시와 다른 내보내기 전용 포맷을 지정합니다.

Salary는 화면에선 $ 포맷, 엑셀로는 숫자 그대로(exportFormatter) 나갑니다.

Fill Handle (엑셀식 채우기)

fillHandle: true(cellSelection 필요)는 선택 범위 우하단에 채우기 핸들을 표시합니다. 핸들을 세로로 드래그하면 숫자 2개 이상은 등차 수열로 외삽하고(1, 3 → 5, 7, 9…), 그 외에는 패턴을 반복합니다. 편집 가능한 셀에만 쓰이고 validator· beforeCellSave를 통과한 값만 반영됩니다.

Salary 셀 두 개를 세로로 드래그해 선택한 뒤, 파란 핸들을 아래로 끌어 보세요.

Merge Cells (연속 값 세로 병합)

mergeCells: ['field'...]는 표시 순서상 연속된 같은 값을 세로로 병합해 보여줍니다 — 병합 구간이 하나의 셀이 되어 값이 세로 중앙에 표시됩니다. 해당 컬럼으로 정렬하면 병합 효과가 커지고, 그룹 헤더·디테일 행에서는 병합이 끊깁니다. 데이터 자체는 그대로라 CSV/클립보드에는 영향이 없습니다.

Product·Status 컬럼이 병합 대상입니다 — 헤더를 클릭해 정렬을 바꾸면 병합이 재계산됩니다.

Column Virtualization — 300 columns (virtualX)

virtualX: true는 가로 뷰포트에 보이는 컬럼(+버퍼 2)만 셀을 렌더링하고 나머지는 폭 스페이서로 대체합니다 — 수백 개 컬럼에서도 행 DOM이 가볍게 유지됩니다. 가로 스크롤 시 컬럼 창이 갱신되고, 고정(pinned) 컬럼은 항상 렌더링됩니다.

가로로 스크롤해 보세요.

Pinned Top Rows · Wrap Text · Auto Height

pinnedTopRows는 헤더 아래에 스크롤과 무관한 고정 행(표시 전용)을 두고 setPinnedTopRows(rows)로 갱신합니다. column.wrapText + autoRowHeight: true는 긴 텍스트를 줄바꿈하고 행 높이를 내용에 맞춰 계산하며(가변 높이 가상화), domLayout: 'autoHeight'는 그리드가 내용 높이만큼 늘어나게 합니다.

Note 컬럼은 wrapText — 행 높이가 내용에 따라 다릅니다. 맨 위 굵은 행이 pinnedTopRows입니다.

Auto-Height Grid (domLayout)

domLayout: 'autoHeight'는 컨테이너 높이 대신 내용 높이만큼 그리드가 늘어납니다 — 세로 스크롤/가상화가 없어지므로 소량 데이터 전용입니다.

이 그리드는 8행 높이만큼만 차지합니다 (컨테이너 높이 불필요).

Utility Options & Events (v2.0)

once(event, fn)(1회 핸들러) · setEnabled(bool)(전체 인터랙션 잠금 오버레이) · column.headerAlign(헤더만 다른 정렬) · showHeader: false(헤더 숨김) · rowValueChanged(행 단위 변경 묶음 — 편집·붙여넣기·채우기 공통) 모음입니다.

Salary 헤더는 headerAlign: 'center' — 셀은 오른쪽 정렬이지만 헤더만 가운데입니다.

Headerless Grid (showHeader)

showHeader: false는 헤더 영역 전체(정렬·필터 UI 포함)를 숨깁니다 — 읽기 전용 리스트나 커스텀 헤더를 직접 만들 때 사용합니다.

헤더 없이 본문만 렌더링된 그리드입니다.

Tree Grid (treeData)

treeData는 계층 데이터를 트리로 표시합니다 — nested(children 배열)와 flat(parentId) 형식을 모두 지원하고, 정렬은 형제끼리, 필터는 매치된 노드의 조상을 유지한 채 동작합니다. expandAllNodes()/collapseAllNodes()/toggleNode()로 프로그램 제어, beforeNodeToggle(취소 가능)/nodeExpanded/nodeCollapsed 이벤트를 제공합니다.

폴더 행의 화살표를 클릭해 펼치고 접어 보세요.

Tree Checkbox — cascade (checkboxSelection)

트리 모드에서는 기존 checkboxSelection 컬럼이 3상태 캐스케이드 체크박스가 됩니다 — 부모를 체크하면 자손 전체가 행 선택되고, 자식 일부만 선택되면 부모가 indeterminate로 표시됩니다 (treeData.cascade: false로 끌 수 있음). 별도 API 없이 선택 API를 그대로 씁니다: getSelectedRows()· selectAll()/deselectAll()·selectionChanged/beforeSelectionChange. headerCheckboxSelection의 헤더 체크박스도 트리 규칙을 따릅니다 — 전체 체크/해제 시 treeData.checkboxDisabled(row) 행은 건드리지 않고, 표시 상태(전체/일부)도 체크 가능한 행만 기준으로 계산합니다. 이 카드는 flat(parentId) 형식 데이터를 사용합니다.

폴더를 체크해 보세요 — 자손 전체가 행 선택되고, license 파일은 비활성입니다.

Tree Summary (treeData.summary)

treeData.summary: true는 column.aggFunc가 지정된 컬럼에서 부모 노드 행에 자손 리프들의 집계값을 표시합니다 (표시 전용 — 데이터는 그대로). 필터를 걸면 남은 리프 기준으로 집계가 다시 계산됩니다.

폴더 행의 Size 컬럼에 자손 파일 크기 합계가 표시됩니다.

Tree Lazy Loading (treeData.fetchChildren)

treeData.fetchChildren(row)는 노드를 처음 펼칠 때 자식을 비동기로 로드합니다 (Promise 반환, 로딩 중 토글이 스피너로 회전). hasChildren(row)가 로드 전 토글 표시 여부를 결정하고, 빈 배열이 오면 리프로 확정됩니다. 실패 시 dataLoadError가 발생하고 접힌 상태로 남아 재시도할 수 있습니다.

폴더를 펼치면 500ms 지연 후 자식이 로드됩니다 (같은 노드는 1회만).

Select Editor — label/value Options

editorOptions는 문자열 배열 외에 { label: '한국', value: 'kr' } 객체 배열도 받습니다 — 드롭다운에는 label이 표시되고, 선택하면 value가 데이터에 저장되어 셀에 표시됩니다 (숫자 value는 타입이 보존됩니다). editor를 선언한 컬럼은 editable: true를 생략해도 편집이 켜집니다 (명시적 editable: false가 우선).

Country 셀을 클릭해 드롭다운에서 나라 이름(label)을 고르면 셀에는 코드(value)가 저장됩니다.

Select Renderer (DataGrid.renderers.select)

select 에디터의 짝꿍 렌더러입니다 — 셀에는 코드(value)가 저장돼 있어도 cellRenderer: DataGrid.renderers.select()가 그 컬럼의 editorOptions에서 label을 찾아 표시합니다. 데이터·정렬·필터·내보내기는 저장된 value 기준 그대로이고, 표시만 label로 바뀝니다. 목록에 없는 값은 원래 표시로 폴백하며, 다른 목록을 쓰려면 DataGrid.renderers.select([{ label, value }, …])처럼 직접 넘길 수 있습니다.

Country 셀은 데이터에 'kr' 같은 코드가 저장돼 있지만 화면에는 label이 보입니다 — 편집해 보세요.

Multiselect · Radio · Checkbox Editors & Renderers

editor에 'multiselect'(체크리스트 패널, 값은 배열)· 'radio'(인라인 라디오 그룹)·'checkbox'(불리언 체크박스)를 지정할 수 있고, 각각 짝꿍 렌더러 DataGrid.renderers.multiselect()(label 칩 목록)· renderers.radio()(value → label)·renderers.checkbox()(표시 전용 체크박스)가 있습니다. multiselect는 editorOptions 순서대로 배열을 커밋하며 내용이 같으면 커밋하지 않습니다.

Skills(더블클릭 → 체크리스트)·Level(라디오)·Remote(체크박스) 셀을 편집해 보세요. Enter/바깥 클릭 = 커밋, Esc = 취소.
